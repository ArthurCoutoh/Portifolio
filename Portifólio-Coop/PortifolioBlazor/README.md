Observação para o Professor sobre o Histórico do Git

Olá professor,

Gostaríamos de esclarecer um detalhe sobre o histórico de versionamento deste projeto. 

Este repositório no GitHub foi criado depois da conclusão do desenvolvimento dos códigos.

Nós desenvolvemos nossos portfólios inicialmente de forma separada e, ao final, unimos tudo em uma única aplicação Blazor (criando o menu central que dá acesso aos portfólios individuais). Somente depois de toda essa junção e de o projeto estar finalizado é que decidimos criar o repositório e subir o código para o GitHub.

Por esse motivo, o repositório apresenta apenas um commit, e não o histórico todo do passo a passo do desenvolvimento. O projeto inteiro já foi comitado tudo junto.
